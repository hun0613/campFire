# 🔥 불멍 캠핑장

밤의 글램핑장에서 장작을 패고, 마법 가루로 모닥불을 물들이며 함께 불멍하는 3D 멀티플레이 게임.

## 실행
```bash
npm install
npm run dev        # http://localhost:3000 (Vite + WebSocket 서버 한 포트)
# 배포
npm run build && npm start
```
### 친구들과 함께 할 때는 배포 모드 추천
```bash
npm run build && npm start   # 번들된 파일이라 폰에서 훨씬 빨리 열려요
```

### 📲 앱(PWA)으로 설치
- 아이폰: Safari → 공유 → "홈 화면에 추가" (http 주소에서도 전체화면 앱처럼 실행)
- 안드로이드/PC: 게임 안의 📲 버튼 또는 브라우저 메뉴 → "앱 설치"
- 정식 설치·오프라인 캐시(서비스워커)는 **https 주소나 localhost** 에서만 동작해요.
  같은 와이파이의 `http://192.168.x.x` 주소로는 안드로이드에서 홈 화면 바로가기로만 추가돼요.

### (개발용) 같은 와이파이에서 테스트하기
서버를 켜면 터미널에 `같은 네트워크: http://192.168.x.x:3000` 주소가 나와요.
같은 와이파이에 연결된 다른 PC·폰에서 그 주소로 접속하면 같은 캠핑장에 들어와요.
macOS에서 "node 수신 연결 허용" 창이 뜨면 **허용**을 눌러 주세요.

같은 서버에 접속한 사람끼리 채팅, 같은 모닥불에 앉기, 가루 효과가 실시간 공유됩니다.

## 인터넷에 배포 (Render)

같은 와이파이가 아니어도, 링크만 있으면 누구나 들어올 수 있게 올리는 방법이에요. https 주소가 생겨서 안드로이드에서도 정식 앱 설치가 돼요.

1. 이 폴더를 GitHub 저장소에 올려요. `node_modules`와 `dist`는 `.gitignore`로 빠져 있어요.
2. [render.com](https://render.com)에 가입하고 **New → Blueprint**를 눌러 저장소를 연결해요.
3. `render.yaml` 설정대로 빌드(`npm ci && npm run build`)와 실행(`npm start`)이 자동으로 진행돼요.
4. 몇 분 뒤 `https://campfire-game-xxxx.onrender.com` 같은 주소가 나오면 그 주소를 공유하면 돼요.

- GitHub에 새 커밋을 올리면 자동으로 다시 배포돼요.
- 무료 플랜은 15분 정도 아무도 없으면 서버가 잠들어요. 다음 첫 접속 때 깨어나느라 30초~1분 정도 걸리고, 그때 타고 있던 모닥불과 장작은 초기화돼요.
- 장작·가루는 기기별로 저장돼서 새로고침하거나 앱을 다시 켜도 유지돼요. 서버가 잠들었다 깨어나도 기기에 저장된 서명 백업으로 복원돼요. 서명 키는 `SAVE_SECRET` 환경변수이고, `render.yaml`에서 Render가 자동으로 만들어요.
- 공개 주소는 Render가 알려 주는 `RENDER_EXTERNAL_URL`을 자동으로 써요. 다른 곳에 올릴 때는 환경변수 `PUBLIC_URL`로 지정해요.

## 게임 흐름
1. 동쪽 **장작 패는 곳** 통나무 앞에서 `E` (꾹) → 도끼질 3번에 장작 1개
2. 장작 5개 → 서쪽 **루미**에게 `E` → 랜덤 마법 가루 3개 (색 8종 × 효과 8종)
3. 공터(3곳) / 글램핑 텐트 앞(10곳) 화로에서 `E` 장작 쌓기 → `E` 불 붙이기
4. 불 앞에서 `E` 앉기 → `1~9` 가루 뿌리기
5. 10분 후 장작이 다 타면 다시 1번부터

📱 모바일: 화면 왼쪽 절반 이동(끝까지 밀면 달리기) · 오른쪽 절반 드래그 시점 · 두 손가락 줌 · 오른쪽 아래 버튼 상호작용 · 가루 탭 · 💬 채팅

PC 조작: WASD 이동 · Shift 달리기 · 드래그 시점 · 휠 줌 · Enter 채팅

## 구조
- `shared/config.js` – 밸런스 수치, 맵 배치(텐트·화로·통나무·NPC), 가루 목록 (서버/클라 공용)
- `server/index.js` – HTTP + WebSocket, 서버 권위 상태(인벤토리, 화로, 좌석, 채팅)
- `src/world.js` 맵/조명 · `src/fire.js` 모닥불 · `src/effects.js` 가루 효과 · `src/character.js` 캐릭터 · `src/main.js` 게임 루프
